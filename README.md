# DWR Open Science GitHub Organization Governance

This repository documents the purpose, scope, and governance of the **DWR-Open-Science** GitHub organization. It supports California Department of Water Resources (DWR) Strategic Plan Action 1.2.2: *Development of Open Science Guidance and Resources* (SP 1.2.2).

The organization is a shared home for resources that help DWR staff develop, publish, and steward reproducible, open-source scientific work. It is intended to complement—not replace—GitHub organizations and repositories already maintained by DWR programs and teams.

## Why this work matters

Open science strengthens the transparency, reproducibility, credibility, accessibility, and longevity of DWR scientific work. It can support collaboration, make scientific products more useful over time, and help DWR adapt to evolving research, computing, and water-resource-management needs.

Openness must be applied responsibly. Not every project, dataset, or product should be public: sensitive information, Tribal data and Indigenous data sovereignty, community-held knowledge, security concerns, legal requirements, and other appropriate limits must guide decisions about access and reuse.

## What belongs in DWR-Open-Science

During the initial phase of SP 1.2.2, this organization will host resources that staff develop, such as:

- Governance, standards, and guidance for open-source scientific work at DWR
- Reusable repository templates and project scaffolding
- Practical guides for common workflows, including starting repositories, contributing, releases, reproducibility, and documentation
- Training and onboarding materials
- Exemplar repositories that demonstrate recommended practices
- Tools, demonstrations, and websites that support open science practice

It may also host code related to the practice of science at DWR when the project fits the organization’s purpose and can be maintained responsibly.

## What does not belong here

This organization is not intended to be a default destination for every DWR repository. Program- or team-specific work should generally remain with the program or team best positioned to own, maintain, and support it. Repositories should not be made public when doing so would conflict with applicable requirements or responsible data and software stewardship.

## Guiding practices

Resources in this organization should be practical, understandable, and reusable and demonstrate best practices. As appropriate for each project, this includes clear documentation, an explicit license, version control, contribution guidance, reproducible environments or dependency information, transparent issue and review workflows, and defined maintenance expectations.

Open-source practice is also a people practice. Contributors and maintainers should have clear roles, attribution, support, and sustainable expectations. The organization will seek to make participation accessible to both technical and non-technical DWR staff.

## Governance and maintenance

This repository will contain the organization’s governance materials as they are developed, including guidance on membership and permissions, repository lifecycle and ownership, contribution and review practices, decision making, and support pathways.

### Charter

The [DWR Open Science GitHub Organization Charter](docs/charter.md) sets out the organization’s purpose, guiding principles, scope, roles, repository expectations, and process for updating its governance. It is a living draft that will be refined as decisions are made and the organization grows.

Materials developed under SP 1.2.2 will be beta tested and refined with DWR users. GitHub is the primary development and hosting environment for these resources; feedback and review may also be gathered through accessible DWR communication channels and software so that participation does not require GitHub experience.

## Status

The DWR-Open-Science organization and its resources are being established as part of the 2026 SP 1.2.2 work. This README is an orientation document and will evolve as governance decisions and supporting materials are adopted.
