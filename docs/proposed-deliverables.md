# Proposed Deliverables for SP 1.2.2

This document describes the proposed deliverables for the reproducible, open-source scientific work stream of Strategic Plan Action 1.2.2 (*Development of Open Science Guidance and Resources*). The work stream will establish the organizational infrastructure, practices, implementation resources, and training needed to develop, publish, and steward reproducible open-source scientific analyses and software.

The work will build on effective existing DWR and external resources and will complement—not replace—GitHub organizations maintained by DWR programs and teams.

## Proposed deliverables

### Departmental standards

Develop a concise, authoritative reference defining expectations for open-source scientific work at DWR. It will address minimum repository standards, reproducibility and publication expectations, and responsibilities for maintaining and contributing to codebases.

### Open science GitHub organization

Establish a DWR GitHub organization for guidance, templates, training materials, demonstrations, websites, and examples. Deliverables include governance; membership and permission conventions; criteria for what belongs in the organization; and landing page documentation that directs users to key resources.

### Repository templates and project scaffolding

Create opinionated, ready-to-use templates for common project types, initially emphasizing R and Python. Templates will provide standardized structures, preconfigured documentation, contribution guidance, and integrated development tooling.

### Task-oriented implementation guides

Produce short, practical, example-driven guides for common workflows, including:

- Starting a new repository
- Building reproducible analyses
- Managing environments and dependencies
- Publishing releases and obtaining DOIs
- Contributing to existing projects
- Opening issues and pull requests

### Training and onboarding resources

Develop lightweight learning pathways that build fluency in version control, collaborative development, and open-source practices. Resources may include short modules, recorded demonstrations, guided exercises, and a curated set of existing DWR-relevant materials.

### Exemplar repositories

Maintain a small set of “gold standard” repositories that demonstrate recommended practices in context and provide working models for staff to adapt.

### Support and maintenance guidance

Define a lightweight approach for sustaining the resources over time, including ownership of templates and standards, update mechanisms, and user support pathways such as designated channels or office hours.

### Workflow integration guidance

Provide guidance for incorporating open-source and reproducible practices into existing project planning, codebase management, and publication workflows so the practices support—not duplicate—existing requirements.

## Initial 2026 priorities

The first phase will focus on:

1. Establishing and governing the GitHub organization.
2. Developing guidance for GitHub use and minimum repository standards.
3. Creating a small set of repository templates and implementation guides.
4. Developing lightweight onboarding and training resources.
5. Documenting baseline security and risk considerations, including sensitive-data handling and secrets management.

More advanced materials—such as comprehensive testing guidance, CI/CD patterns, containerization, pipeline orchestration, expanded exemplar repositories, and detailed maintenance frameworks—may follow as capacity allows.

## Primary audience

DWR staff who develop, maintain, review, publish, or support scientific analyses and software, including both technical and non-technical collaborators.

## Delivery approach

The proposed resources will be beta tested and refined with DWR users. GitHub will be the primary public development and hosting environment for open-source resources, while policy review, management input, and broader organizational feedback may be gathered through accessible DWR channels such as SharePoint, briefings, presentations, working group meetings, and targeted review sessions.
